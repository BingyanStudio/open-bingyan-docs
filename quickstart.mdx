<Steps>
  <Step title="创建一把 API Key">
    打开[控制台](https://open-dev.bingyan.net/console/)，用 Hustoday 账号登录，点「创建 API Key」。

    名称写它给谁用（比如 `Claude Code`）。权限默认勾好了「只读」——课程、资料、动态、你自己的课表都能读，但不能替你发帖、收藏或改课表。对 Agent 来说这就是全部需要的。

    <Warning>
      Secret 只出现这一次，形如 `byk_test_…`。它代表你本人，不要贴进群聊、不要提交到 Git。
    </Warning>
  </Step>

  <Step title="复制 MCP 配置，粘进你的 Agent">
    Secret 出现的那一屏有一个 **复制 MCP 配置** 按钮。它复制的是这段（Secret 已填好）：

    ```json
    {
      "mcpServers": {
        "open-bingyan": {
          "type": "http",
          "url": "https://open-dev-api.bingyan.net/mcp",
          "headers": { "Authorization": "Bearer byk_test_…" }
        }
      }
    }
    ```

    <Tabs>
      <Tab title="Claude Code">
        粘到项目根目录的 `.mcp.json`（没有就新建）。或者在终端：
        ```bash
        claude mcp add --transport http open-bingyan https://open-dev-api.bingyan.net/mcp \
          --header "Authorization: Bearer byk_test_…"
        ```
      </Tab>
      <Tab title="Cursor">
        粘到 `~/.cursor/mcp.json`。
      </Tab>
      <Tab title="Codex">
        `~/.codex/config.toml` 里加一段：
        ```toml
        [mcp_servers.open-bingyan]
        url = "https://open-dev-api.bingyan.net/mcp"
        http_headers = { Authorization = "Bearer byk_test_…" }
        ```
      </Tab>
    </Tabs>

    重开一次 Agent。
  </Step>

  <Step title="问它一个问题">
    > 帮我看看「中国文化史」哪个老师评价最好，点名严不严？

    Agent 会先调 `search_courses`，再对每位老师调 `course_detail`，然后告诉你：李琼等的 10 条评价全部"很赞"，不点名不签到，期末论文；白杨等 44 条评价、39 条"很赞"，要签到、考试、有作业；陈文龙等还没有评价。附上学生原话和评价时间。

    **看到这样的回答，就接通了。** 接下来可以直接问「我明天几点有课」「找一下一元分析的往年试卷」「这学期有哪些不跟我课表冲突的公选课」。全部能问的见 [MCP 工具](/mcp-tools)。
  </Step>
</Steps>

## 不用 Agent，直接调接口

同一把 Key 也是 REST API 的凭证。所有接口在 `https://open-dev-api.bingyan.net/v1/…`，请求头带 `Authorization: Bearer <Key>`：

```bash
curl "https://open-dev-api.bingyan.net/v1/courses/search?keyword=文化史" \
  -H "Authorization: Bearer byk_test_…"
```

```json
{
  "items": [
    { "name": "中国文化史", "teacher": "李琼等", "credit": "2",
      "quality": 1, "assessment_count": 10,
      "rollcall_way": "不点名不签到", "assessment_way": "论文", "has_assignment": "有作业" }
  ],
  "total": 4
}
```

`quality` 是 1–3 分，**越低越好**（1 = 所有评价都是"很赞"），-1 表示还没有评价。每个接口需要哪个权限见[能力与权限](/capabilities)，完整参数见 [API Reference](/api-reference/搜索公开课程)。

写 Skill 的话，[hust-skills](https://github.com/BingyanStudio/hust-skills) 里的 `hust-course-picker`、`hust-timetable`、`hust-study-materials`、`hust-campus-feed` 就是基于这些接口的现成例子；它们优先用 MCP 工具，没有 MCP 时从环境变量 `OPEN_BINGYAN_API_KEY` 读 Key。

<Accordion title="遇到问题">
  - **Agent 里看不到 open-bingyan 的工具**：配置文件位置不对，或没有重开 Agent。用 curl 直接调一次 `/v1/me` 能分清是 Key 的问题还是 Agent 配置的问题。
  - **`401 invalid_api_key`**：Key 复制不完整，或已撤销。`byk_test_` 的 Key 只对 `open-dev-api.bingyan.net` 有效。
  - **`403 insufficient_scope`**：这把 Key 没勾该接口的权限。权限创建后不可改——新建一把带该权限的，撤销旧的。MCP 工具会直接告诉 Agent 缺哪个权限并给出带预选的控制台链接。
  - **`not_found: no synced terms`**：课表工具需要你先在 Hustoday App 里同步过课表。
  - **`429 rate_limit_exceeded`**：一分钟超过 120 次。看 `Retry-After`。
  - **`503 upstream_unavailable`**：背后的校园服务没有响应，稍后再试。
  - **羽球返回 `500 Failed to get user`**：你的账号没在羽球平台注册过。上游自己的错误会原样返回。
</Accordion>
