description: "用 API Key 查询自己的公开资料"
---

从创建凭证到拿到响应通常只需两分钟。完整路径、参数和 Scope 见 [API Reference](/api-reference)。

## 1. 创建 API Key

打开[开发者控制台](https://open.bingyan.net/console/)，使用 Hustoday 账号登录，新建一把仅用于本地实验的 Key，并选择 `profile:self:read` Scope。

<Warning>
  Secret 只展示一次。请保存在密码管理器或本地环境变量中，不要提交到 Git。
</Warning>

## 2. 发起请求

```bash
export OPEN_BINGYAN_API_KEY="你的 API Key"

curl --request GET \
  --url https://open-api.bingyan.net/v1/me \
  --header "Authorization: Bearer $OPEN_BINGYAN_API_KEY"
```

API Key 代表当前登录用户，因此个人数据接口不接受 `cid`、学号等身份参数。

## 3. 接进 Agent

平台也提供 MCP 入口：

```text
https://open-api.bingyan.net/mcp
```

在支持远程 MCP 的 Agent 中配置该地址，并以 Bearer Token 方式携带同一把 API Key。建议为每个 Agent 单独创建 Key，只开放它会使用的 Scope。

<Tip>
  遇到 `401` 先检查 Key 是否完整；遇到 `403` 检查是否选择了接口要求的 Scope。
</Tip>
