你在 Claude Code 里问一句：

> 这学期公选课里，不跟我课表冲突、评价好、不点名的有哪些？

它会调用冰岩开放平台的 `find_free_electives`，拿到你在 Hustoday 同步的课表和爱选修上两千门课的学生评价，然后回答：

```text Claude Code 的回答 · 事实逐字来自 2026-09-23 的真实调用 wrap
读了你 2026-2027 秋季学期同步的 19 节课。爱选修上有 156 门公选课
至少有一个课堂不和它冲突。按评价排序，不点名的前几门：

1. 中国文化史 · 李琼等 · 2 学分
   周一或周二 9–11 节（3–12 周），西十二楼 N203 / 东九楼 B203
   10 条评价全部"很赞"。学生报告：不点名不签到 / 论文 / 有作业。
   "不用签到，中间交了一次作业，很简单，结课就是最后一节课开卷答
    两条题目，给分也不错 85+"（4 人赞同，2022-08）

2. 未来的能源 · 龚勋等 · 2 学分
   周二 9–11 节（3–12 周），东九楼 D103
   16 条评价，15 条"很赞"。点名 / 论文 / 无作业。
   "点名两到三次，平时分只有 20%……论文也不难"（2021-11）

3. 神奇的光学实验 · 何艳艳等 · 2 学分
   周一或周三 9–12 节，光电信息大楼
   10 条评价全部"很赞"。签到 / 其他 / 无作业。
   "实验做的快来三次就可以了……最后只用交个实验报告，打分高"（2022-08）

注意：这些评价大多是 2021–2023 年的，老师和考核方式可能变了。
要我对照你的课表确认周一晚上是不是真的空着吗？
```

这个问题以前没有任何工具能回答：爱选修有评价但没有你的课表，课表里没有评价。平台把两边接在一起。

## 三分钟接入

1. 用 Hustoday 账号登录[控制台](https://open-dev.bingyan.net/console/)，创建一把 API Key。默认勾好的"只读"就够用。
2. 点 **复制 MCP 配置**，粘到 Claude Code、Cursor 或 Codex 的 `.mcp.json`。
3. 重开 Agent，开始问。

## 你的 Agent 会多出什么

| 能力 | 来自 | 你可以问 |
| --- | --- | --- |
| 课程评价与选课 | 爱选修 | "这门课点名吗？作业多吗？哪个老师评价好？" |
| 不冲突的公选课 | 爱选修 + 课表同步 | "帮我挑几门不跟课表撞的人文类公选课" |
| 我的课表 | Hustoday 课表同步 | "我明天几点有课？在哪？""本周哪天下午空？" |
| 学习资料 | 1037wiki | "找一下一元分析的往年试卷" |
| 校园动态 | Hustoday | "最近有什么社团在招新？" |

全部 13 个工具和 2 个内置 prompt 见 [MCP 工具](/mcp-tools)。

## 个人数据只属于你

课表、收藏、个人资料这类数据，平台只会以 **你自己的身份** 去取。API Key 绑定你的 Hustoday 账号，没有任何参数能让它读别人的数据。Key 可以随时撤销，每分钟 120 次调用的上限保护上游服务。

<Note>
  这是校内测试环境。正式上线后地址会换，那时再重新创建 Key 即可。
</Note>
