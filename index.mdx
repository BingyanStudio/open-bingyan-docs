冰岩开放平台把冰岩作坊各产品的能力整理成一把 API Key 就能调用的接口，并提供同一把 Key 可用的 MCP 服务器。课程评价、学习资料、校园动态、你自己的课表——接进你的 Agent、脚本或应用。

## 当前已接入的能力

| 能力 | 来自哪个产品 | 主要用途 |
| --- | --- | --- |
| 课程与评价 | 爱选修 | 搜索公选课，看学生评价、点名/考核/作业情况、上课时间 |
| 课表 | Hustoday 课表同步 | 读取你同步过的学期课表；MCP 直接给出某天/某周的课和时间 |
| 校园动态 | Hustoday | 浏览、搜索、发布和互动 |
| 学习资料 | 1037wiki | 搜索往年试卷、笔记、课件，读取资料页和文件 |
| 羽球约球 | 羽球平台 | 查看和参与约球活动 |
| 吃什么 | Foodie | 公共 GraphQL 查询 |
| 通知、反馈、资料 | Hustoday | 个人通知、提交反馈、读取自己的公开资料 |

完整的路径、参数、响应和可交互示例见 **API Reference**；每个路径需要的 Scope 见[能力与权限](/capabilities)。

<Note>
  请勿把 API Key 放入公开仓库或前端代码。
</Note>
