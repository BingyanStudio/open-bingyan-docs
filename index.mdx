冰岩开放平台提供稳定、统一的接口，让学生开发者和校内团队不必重复处理账号、课表、课程、通知与资料服务的接入细节。

<CardGroup cols={2}>
  <Card title="做一个懂你课表的 Agent" icon="calendar" href="/quickstart">
    用一把代表你本人的 API Key，让 Agent 在授权范围内读取个人数据。
  </Card>
  <Card title="管理 API Key" icon="key" href="/console">
    登录控制台，创建按用途隔离、可独立撤销的开发凭证。
  </Card>
</CardGroup>

## 当前可以做什么

- 查询自己的账号资料
- 查询课程与课表信息
- 搜索爱选修课程和评论
- 给自己发送通知
- 查询与下载 1037 Wiki 资料
