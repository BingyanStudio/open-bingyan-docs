冰岩开放平台提供统一的 API Key 认证入口，把冰岩作坊各产品的能力整理成可以直接调用的接口。你只需要创建一把 Key，再按接口要求选择 Scope。

<CardGroup cols={2}>
  <Card title="先跑通一次 API" icon="play" href="/quickstart">
    创建一把专用 Key，按指南发起你的第一条请求。
  </Card>
  <Card title="管理 API Key" icon="key" href="https://open-dev.bingyan.net/console/">
    登录控制台，创建按用途隔离、可独立撤销的开发凭证。
  </Card>
</CardGroup>

## 当前已接入的能力

| 能力 | 主要用途 |
| --- | --- |
| 账号与身份 | 读取当前 API Key 所有者的公开资料 |
| 课程与课表 | 搜索课程，读取收藏、已修课程、评价和学期课表 |
| Hustoday | 查询、发布和管理信息流、评论、点赞、收藏与关注 |
| 1037 Wiki | 搜索页面、合集、分类、评论、互动和文件下载 |
| 羽毛球与吃货 | 调用羽毛球服务和 Foodie GraphQL 能力 |
| 通知与反馈 | 查询和管理个人通知，提交反馈 |

完整的路径、参数、响应、认证方式和可交互示例见 **API Reference**。接口对应的上游服务未配置或暂时不可用时，会返回 `503`，具体以响应为准。

<Note>
  请勿把 API Key 放入公开仓库或前端代码。
</Note>
